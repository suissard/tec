6. Adhésion et bénévolat — refonte complète
C'est la partie qui demande le plus de travail. Aujourd'hui, adhésion et bénévolat sont mélangés. Ce sont deux démarches différentes et il faut que ça se voie.


6.1 — Séparer nettement les deux
Je veux deux espaces vraiment distincts sur la page :

une partie Adhésion — on rejoint l'association
une partie Bénévolat — on vient donner un coup de main



6.2 — Les trois formules
Formule => Tarif => Ce que ça donne
Membre individuel => 1 € / an => Réservé aux personnes qui veulent être bénévoles. Donne les droits bénévoles et l'accès au staff.
Membre sympathisant => 5 € / an => Soutient l'association. N'octroie pas les droits bénévoles, donc pas d'accès au staff.
Entité morale (association) => 50 € / an => Inchangée, telle qu'elle est aujourd'hui.


La différence entre les deux formules individuelles doit sauter aux yeux. C'est le point sur lequel les gens se trompent.



6.3 — Le formulaire de candidature bénévole
Retirer le tarif de partout dans ce formulaire. Le « 1 € / an » apparaît dans l'encart récapitulatif, dans le texte d'introduction et dans le libellé du bouton d'envoi. Je ne veux rien de tout ça.

La question de l'adhésion se règle en vocal, pendant l'entretien. Afficher un prix sur un formulaire de candidature bénévole, ça freine les gens à l'inscription alors que ce n'est pas le sujet à ce moment-là.

Les champs :

« Pseudo gaming / d'usage » → renommer « Pseudo Discord » et le rendre obligatoire
« Identifiant Discord » → supprimer ce champ, il fait doublon avec le précédent



6.4 — Les domaines d'investissement
Case actuelle => Action
Régie technique & Streaming => Renommer Broadcast
Communication & Réseaux Sociaux => Renommer Communication
Graphisme, Vidéo & Création => Renommer Service créatif
Accueil, Billetterie & Staffing => Renommer Événementiel
Projets associatifs & Vie du collectif => Renommer Vie associative
Presse, Rédaction & Photographie => Supprimer
Logistique & Montage événementiel => Supprimer — intégré dans Événementiel
Arbitrage & Gestion de tournois => Supprimer
— => Ajouter une case « Autre »


On arrive donc à six cases : Broadcast, Communication, Service créatif, Événementiel, Vie associative, Autre.

Ces intitulés correspondent à nos pôles réels. C'est plus court, et ça permet de router directement une candidature vers le bon responsable.
